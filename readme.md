# Dopamine Bounce

An **ADHD-simulator platformer clicker game**.
Made for **hackclub haven** a teen gamejam hackaton in **2 days**.

You run two games at once while endless distractions pull at your attention.

How to play

- **Click the CPS ball** to build your score.

- **Juggle the chaos**: speed, effects, distractions and more, all changing at once.

- **Compete with friends** for the highest score.

Everything is available on github at https://github.com/AnCarsenat/DopamineBounc music and art is all rights reserved and the code is gpl 3 so feel free to modify.
